# Moonstone Match

Full-colour Python 3 neon match-3 arcade for ElbowOS.

Swap adjacent glowing gems to clear matches of 3+. Gems cascade and refill. Score climbs with combos.

Featured: https://x.com/ElbowOS

## Play interactively

```bash
pip install -r requirements.txt
python3 moonstone_match.py --play
```

Click adjacent gems to swap. Escape to quit.

## Record a 9:16 reel

```bash
python3 moonstone_match.py --record
```

Produces a 15-second 1080x1920 MP4 with autoplay.
